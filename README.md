# CSS Food Landing Page

This is a simple food landing page I built while learning CSS.

After working on a few HTML projects, I wanted to start using CSS to make my webpages look better and practice different styling techniques. This project is one of my first steps in that direction.

## What I Used

- HTML5
- CSS3

## What I Practiced

While building this project, I practiced:

- Background images
- Colors and fonts
- Width and spacing
- Padding and margins
- Borders and border-radius
- Positioning
- Navigation styling
- Button styling
- Hover effects
- Form styling

## About the Project

The page includes a simple navigation bar, a food-themed background, an order button, and a contact form.

The main goal of this project was not to build a complete restaurant website, but to practice the CSS concepts I have learned so far and apply them to a real webpage.

## Future Improvements

As I learn more CSS, I would like to improve this project by:

- Making it responsive
- Improving the layout
- Adding more sections
- Creating a better mobile design
- Improving the overall user interface
